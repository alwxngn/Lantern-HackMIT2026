# Portal theme

The shipped UI is the teal palette and type in `src/index.css` and `index.html`.

| Token | Value | Use |
|---|---|---|
| `--color-brand` | `#2b6b68` | Primary teal, theme color |
| `--color-ink` | `#153a3b` | Headings |
| `--color-bg` | `#f3f7f6` | Page background |
| `--font-display` | Poppins | Headings |
| `--font-body` | Inter | UI and body text |

Poppins (weights 500–700) and Inter (weights 400–600) load from Google Fonts in `index.html`.

An earlier “Ease Health” style sheet (forest green, a serif display face) was not applied to this build. Treat `src/index.css` as the source of truth.
